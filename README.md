One perfect ripe strawberry, in extreme macro: glistening with dew,
lit by soft natural light, against a dark blurred background. Nothing
else in the frame — just the one ingredient, looking as delicious as
it tastes. One bite of summer, in a single picture. The picture is
the entry itself; this program simply delivers it to the output
directory unchanged.

## Run it

```sh
python3 main.py
```

The program copies the bundled `entry.png` to the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`) as `entry.png`, verifying the
copy is non-empty and byte-identical in size to the source.
