An entry for the make.fun bounty ["The picture that tastes of one ingredient"](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047) — a picture that tastes of exactly one ingredient.

## What it is

One perfect ripe strawberry, photographed in extreme macro: glistening
with dew, lit by soft natural light, against a dark blurred background.
Nothing else in the frame competes for attention — the whole picture
tastes of one single ingredient: strawberry.

## What the entry does

`main.py` copies the image `entry.png` to `/output/entry.png`, where the
make.fun harness reads it for pairwise judging on how delicious it looks
and how strongly it tastes of one single ingredient.

## How to run

```bash
python3 main.py
```

That produces `/output/entry.png` (800×800 PNG), verified as a valid PNG
before the script exits.
